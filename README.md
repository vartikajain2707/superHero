SUPER HERO APPLICATION

🚀<b>Features:</b>

🔍 <b>Search Bar</b>
1. A drop down menu as the user types the characters.
2. Debouncing 
3. Should ensure that parallel requests should be handled gracefully.

🦸 <b>Super Hero Details</b>

On selecting a superhero from the dropdown, the UI displays:
 1. Biography
 2. Photo

<b>Superhero Comparison (Up to 5 Heroes)</b>
  1. Each superhero is displayed in a 6 column grid. First column should be the keys. 
  2. Each column displays the photo of the superhero on top and compares the powerstats of each superhero in the other rows.
  3. ⭐<b>BONUS POINT:</b> On mouseover to a particular key, the superhero which has the best score of that powerstat is highlighted. For example when we hover to “Strength” powerstat highlight the superhero which has the highest value of “Strength”.

🏃‍♂️<b>To run:</b>

npm install

npm run dev
